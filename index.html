Security & access

Shared shop access with device-level remembered sessions.

Shared password: WEFIXIT

The current shared key is verified by Apps Script. Each browser stores its signed session token locally. Change the key in the Apps Script project when staff access should be revoked.

Because all workers share one password, it is not individual identity verification. Avoid saving sensitive device unlock codes or customer banking information.
